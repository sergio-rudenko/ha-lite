# Сопряжение S570HD ↔ ha217b

Только Bluetooth-пара. Дозвон и панель — следующим шагом.

## На нетбуке (192.168.8.139)

```bash
cd ~
# скопируйте сюда bluetooth/pair.sh из этого репозитория, затем:
sudo bash pair.sh
```

Скрипт ставит `bluez` / `bluez-tools` при необходимости, включает адаптер, задаёт имя `ha217b` и ждёт пару с PIN `1234`. Окно не закрывайте, пока навигатор не спарится.

## На навигаторе

1. Bluetooth → поиск устройств  
2. Выбрать **ha217b**  
3. PIN **1234**  

Когда в списке устройств нетбук появится как paired — напишите, перейдём к Make New Connection и дозвону.
