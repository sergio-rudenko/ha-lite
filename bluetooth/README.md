# Сопряжение S570HD ↔ ha217b

## Если на навигаторе есть поле PIN, а клавиатуры нет

Так бывает на WinCE. Не вводите PIN на навигаторе.

### Вариант A — без PIN (предпочтительно)

На нетбуке остановите старый `bt-agent` (Ctrl+C) и запустите:

```bash
sudo bash pair.sh
```

По умолчанию режим Just Works: SSP включён, PIN не спрашивают. На навигаторе снова выберите **ha217b** и только подтвердите пару.

### Вариант B — пару начинает нетбук

На навигаторе включите видимость Bluetooth. На нетбуке найдите адрес:

```bash
sudo bluetoothctl
# scan on
# devices
# Controllers / Device … — адрес вида AA:BB:CC:DD:EE:FF
```

Затем:

```bash
sudo bash pair.sh --to AA:BB:CC:DD:EE:FF
```

PIN `1234` подставляет агент на нетбуке.

### Клавиатура WinCE, если всё же нужен ввод

- ткните в поле PIN — иногда появляется цифровая панель;
- иконка клавиатуры в трее;
- запустите `ToggleInputPanel.exe` из проводника (часто в ResidentFlash2).

## Только после успешной пары

Make New Connection → устройство **ha217b** → номер `*99#`.
